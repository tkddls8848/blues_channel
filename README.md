# blues_channel

음악 생성 프로젝트 두 개가 한 저장소에 있다. 둘 다 `remote_coding/gpu-art` 음악 팟(ACE-Step 1.5 XL)으로 곡을 만든다.

| 폴더 | 내용 |
|---|---|
| `lonely_blues/` | 유튜브 채널 "Lonely Blues · 혼자인 밤의 플레이리스트": 블루스·카페재즈·피아노·로파이 연주곡 롱폼. 계획서는 `lonely_blues/docs/PLAN.md` |
| `latin_chant/` | 라틴어풍 종말론 주문 가사를 끝없이 바꿔 끼우는 곡 생성 아이디어. 발전하면 별도 저장소로 옮긴다. 메모는 `latin_chant/docs/PLAN.md` |
| `tools/` | 두 프로젝트가 같이 쓰는 생성 도구(`ace_step.py`) |

생성된 음원(`runs/`, `*.flac` 등)은 커밋하지 않는다.
