# 바꿔 전투 시퀀스 수정안

첫 6초 시험의 둔한 움직임과 부드러운 입체 명암을 수정한다. 새 검객과 상대의 디자인을 고정하고, 짧은 교전을 이어 원곡 2:50~3:10의 20초 전투를 완성한다.

[20초 전투 수정 영상](renders/veo-3.1-fast-720p-duel-v2/bakkuo-170-190.mp4)

6개 원본 영상의 생성과 합성을 완료했다. 결과는 1280×720, 24fps, 정확히 20초다. 생성 모델의 소리 대신 원곡 2:50~3:10을 사용했다. 생성은 컷마다 1회씩 총 6회, 예상 추가 API 요금은 US$2.40이다.

## 수정 기준

- 주인공은 낮은 삿갓으로 눈과 코를 가린다. 상대는 각진 광대와 턱, 좁고 집중한 눈매를 가진 마른 검객으로 바꾼다.
- 베가본드를 참고한 사실적인 붓끝 인체 묘사와 강한 먹선을 기준으로 삼는다. 부드러운 피부 명암과 게임 캐릭터 같은 입체 표현은 줄인다.
- 무기는 긴 가는 외날검, 작은 코등이, 짧고 끝이 둥근 손잡이로 고정한다. 한 인물당 검 한 자루이며 양쪽에 날이 달린 무기로 바뀌지 않게 한다.
- 공격은 0.2~0.4초의 빠른 이동, 1~2프레임의 짧은 충돌, 즉각적인 반동으로 지시한다. 오랫동안 칼을 맞댄 자세나 느린 선회는 피한다.
- 4초 원본 6개를 생성해 20초로 편집한다. 앞의 두 공방은 프레임 보간 없이 1.2배 재생으로 짧게 압축한다. 원곡은 속도를 바꾸지 않는다.
- 최종 합성에서는 약한 윤곽 선명화만 적용했다. 정지 시안을 대신 늘이거나 프레임 보간으로 중간 동작을 합성하지 않았다.

## 생성과 결과

실행 설정은 veo-jobs-v2.json이다. 기존 시험과 다른 duel-v2 폴더에 작업과 결과를 저장한다. Fast 720p를 사용하면 원본 24초 1회씩 생성의 예상 추가 API 요금은 US$2.40이다. 자동 재생성은 하지 않는다.

```powershell
python flows/scripts/veo_pipeline.py quote --jobs veo-jobs-v2.json
python flows/scripts/veo_pipeline.py generate --jobs veo-jobs-v2.json --budget-usd 2.40
python flows/scripts/veo_pipeline.py render --jobs veo-jobs-v2.json
```

생성 후 칼과 손의 형태, 상대 얼굴의 일관성, 실제 발놀림과 무장 해제의 결과를 확인한다. 이 문서의 동작은 생성 목표이며, 결과가 목표대로 나왔는지는 영상 검수에서 구분해 기록한다.

## 결과 확인

상대 얼굴은 첫 시험의 둥근 인상에서 각진 얼굴로 바뀌었고 반응 접사에서 새 형태가 유지된다. 긴 칼날과 낮은 삿갓이 유지되는 구간을 확인했다. 마지막에는 상대의 칼이 바닥에 놓이고 빈 손이 보여 공방의 결과가 전달된다. [최종 비교 화면](renders/veo-3.1-fast-720p-duel-v2/final-review.jpg)과 [마지막 화면](renders/veo-3.1-fast-720p-duel-v2/last-frame.jpg)을 보관한다.

움직이는 일부 프레임에는 모델이 만든 흐림과 옷의 세부 변화가 남는다. 편집과 윤곽 선명화로 이를 전부 제거했다고 보지는 않는다. 추가 유료 재생성은 하지 않았다.
