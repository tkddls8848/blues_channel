# RISE 전투 연출 참고 이미지

사용자 지정 영상은 [RISE Worlds 2018](https://www.youtube.com/watch?v=fB8TyLTD7EE)이다. 이 폴더의 JPG는 [Fortiche 공식 제작 소개](https://forticheprod.com/portfolio/rise/)에 연결된 공개 포트폴리오 영상에서 연출 검토를 위해 추출한 참고 화면이다. 제작 시안이나 최종 뮤직비디오의 삽입 소재로 사용하지 않는다.

- 출처 영상: https://fortiche.b-cdn.net/wp-content/uploads/2025/04/Fortiche_projects_rise.mp4
- 파일 이름의 숫자는 해당 포트폴리오 영상에서 추출한 초 위치다. 사용자 지정 YouTube 영상의 타임코드와 일치한다고 가정하지 않는다.
- 검토 범위는 정지 화면의 구도, 원근, 인물의 크기와 동작 자세다. 기획서의 가속과 충돌 편집 길이는 본 프로젝트에 제안하는 연출이며 원본의 프레임별 분석 결과가 아니다.
- 새 시안은 프로젝트의 기존 검객 시안을 편집해 생성했다. 이 참고 JPG들은 이미지 생성의 입력으로 사용하지 않았다.
