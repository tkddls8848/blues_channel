# 첫 전투 6초 테스트 결과

[원곡을 붙인 테스트 영상](renders/shot-04-test/shot-04-with-bakkuo.mp4)

- 장면: SHOT 04 검객의 무기 너머로.
- 모델: Gemini API의 Veo 3.1 Fast.
- 영상: 6초, 1280×720, 24fps, H.264.
- 배경음: 사용자 지정 곡 영상의 2:50~2:56. 생성 모델의 오디오 대신 원곡을 사용했다.
- 생성 요청: 1회. 예상 API 요금 US$0.60이며 추가 생성은 하지 않았다.
- 범위: 첫 전투 한 컷의 시험 결과. 전체 35초 영상은 아직 제작하지 않았다.

## 확인 결과

시작 화면은 시안의 한지색과 무기 옆 구도를 따른다. 중반 이후 카메라가 주인공 밖으로 빠져 두 사람을 바라보는 구도로 변한다. 후반의 옷과 갑옷은 첫 시안보다 부드럽고 입체적인 명암으로 바뀐다. 동작은 생겼으나 주관적인 카메라 유지와 명료한 먹선 유지는 다음 수정이 필요하다.

이번 요청은 한 번의 시험 생성으로 끝냈다. 추가 비용이 드는 재생성은 실행하지 않았다.

[앞 중간 끝 비교 이미지](renders/shot-04-test/contact-sheet.jpg)는 0초, 3초, 5.75초를 비교한다.
