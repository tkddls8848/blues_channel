바꿔 / Blender 전투 연출 수정 2

요청 기준
인물 디자인은 기존 영상 시안의 낮은 삿갓과 해진 검은 도포,
상대의 각진 얼굴·수염·투구·좁은 갑옷을 참고한다.
사용자가 첨부한 action-reference.png는 낮은 무게중심과 넓은 발 디딤,
상체를 비틀어 올리는 검의 교차, 옷자락의 방향을 참고한다.
이미지 자체나 RISE 영상은 출력에 삽입하지 않는다.

출력
renders/blender-duel-v2/bakkuo-blender-v2-155-190.mp4
renders/blender-duel-v2/bakkuo-ink-duel-v2.blend
renders/blender-duel-v2/choreography.json
renders/blender-duel-v2/verification.json

구성
정확히 35초, 960x540, 24fps, 840프레임.
제공한 곡의 2:35~3:10을 원래 속도로 사용한다.

곡 2:35~2:40 / 영상 0~5초: 먼 대치, 호흡과 작은 옷자락 움직임.
곡 2:40~2:44 / 영상 5~9초: 낮게 든 검과 손의 접사.
곡 2:44~2:47.8 / 영상 9~12.8초: 얼굴을 가린 삿갓.
곡 2:47.8~2:50 / 영상 12.8~15초: 원경으로 돌아와 간격을 보여줌.
곡 2:50 이후 / 영상 15초 이후: 첫 발 디딤과 짧은 교전.
이후 무기 접사, 낮은 전장 전경, 상대 얼굴, 어깨 뒤 반격과 결착을 잇는다.

변경
첫 교전에서 주인공의 골반을 낮추고 앞무릎을 접으며 뒷다리를 뻗었다.
어깨와 골반을 서로 다르게 회전시켜 상체의 비틀림을 추가했다.
칼날은 130cm, 밑부분 폭 25mm, 두께 3mm이며 작은 곡률을 준다.
검은 척추선과 밝은 날선을 함께 써서 종이 위에서도 윤곽을 구분한다.
두 손의 그립, 가느다란 칼날, 상대의 투구·찰갑·수염·머리카락을 추가했다.
무장 해제 뒤에도 손이 검을 따라 날아가지 않도록 손과 검의 제어를 분리했다.
짧은 붓 결은 옷 표면의 좌표에 고정하고 윤곽선은 별도로 유지한다.
이전 22초 영상과 작업 파일은 별도 폴더에 그대로 남아 있다.

제작 단계
절차적으로 만든 3D 인물의 연출 시험본이다.
기존 영상 인물의 디자인 특징을 참고했지만 얼굴과 옷을 정확히 재현한 모델은 아니다.
첨부 이미지의 정교한 인체 드로잉과 붓선 수준은 아직 구현하지 못했다.
옷은 직접 만든 분할 메시이며 실제 천 시뮬레이션을 쓰지 않았다.
프레임별 객체 애니메이션이므로 일반적인 전신 아마추어 리그와는 다르다.
동작 수정의 기준 파일은 scripts/blender_duel_v2.py다.

재실행 / 프로젝트 루트 PowerShell
& flows/scripts/render_blender.ps1 -Revision 2
기존 프레임 합성만: & flows/scripts/render_blender.ps1 -Revision 2 -EncodeOnly
처음 22초 버전 재실행: & flows/scripts/render_blender.ps1 -Revision 1

실행 / 편집
Open-Blender.cmd를 실행하면 최신 35초 .blend 작업본을 연다.
Space로 재생하거나 타임라인을 이동할 수 있다.
기본 저장 위치는 핵심 교전 자세인 375프레임이다.
전투 시작은 361프레임(영상 15초), 실제 첫 발 이동은 약 15.05초다.

검사
렌더 프레임 840개 존재 여부, H264 영상, AAC 음성, 해상도,
24fps, 정확한 35초 길이와 전체 디코딩을 render_blender.ps1이 확인한다.
검사 결과는 verification.json에 저장된다.
840프레임의 팔·다리 길이 변화는 scripts/audit_blender_duel.py로 검사했다.
분할 메시 관절 계산의 허용 길이 편차는 12mm이며 결과는 limb-audit.json에 있다.
영상 생성 API 호출은 없고 추가 API 요금은 0이다.
