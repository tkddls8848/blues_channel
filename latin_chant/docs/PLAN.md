# Latin Chant — 아이디어 메모 (가칭)

> 우리가 만든 모체곡 하나의 멜로디를 고정하고, 라틴어풍 종말론 주문 가사만 끝없이 바꿔 끼우는 "자기복제 패러디" 곡 생성기

- 작성일: 2026-10-14
- 상태: 아이디어 — 발전하면 별도 저장소로 옮긴다. 그래서 이 폴더는 `lonely_blues/` 를 참조하지 않는다.
  - 지금 함께 쓰는 것은 저장소 최상위의 `tools/ace_step.py` 하나뿐이다. 옮길 때는 이 파일을 복사해 간다.
- 생성 인프라: `remote_coding/gpu-art` 음악 팟(ACE-Step 1.5 XL, MIT)

## 0. 출발점

- **레퍼런스 느낌:** 「Воланд」(이고리 코르넬류크, 2005년 드라마 「거장과 마르가리타」)의 "INRI INRI ABRACADABRA INRI INRI" 부분
  - 저작권이 살아 있는 곡이다. **느낌만 참고하고 음은 하나도 가져오지 않는다.**
- **같은 틀에 가사만 다른 곡의 예:** HEAVEN SAYS의 커버와 리믹스들(MANDELA MIX, Cover)
  - 원곡 멜로디를 그대로 쓰기 때문에 번역 영상조차 "수익 창출 불가"다.
  - 즉 수익이 원곡 권리자에게 간다. 무한 복제가 가능하다는 증거가 아니라, 남의 멜로디로는 안 된다는 증거다.

## 1. 저작권 고찰 요약

- **보호받지 않는 것(아이디어):**
  - 장르, 분위기, 편성(남성 저음 합창, 오르간, 의식 같은 북)
  - "라틴어 종말론 주문"이라는 개념
  - 추상적인 음절 구조
  - INRI, Abracadabra 같은 공공 영역 단어
- **보호받는 것(표현):** 멜로디(음 순서와 리듬의 결합)와 가사
  - 남의 멜로디에 가사만 바꾸면 2차적 저작물이다.
  - 한국은 패러디 항변이 매우 좁다. 2001년 「컴배콤」(서태지 「컴백홈」 패러디)이 침해로 판단됐다.
- **"느낌"만 가져가도 완전히 안전하지는 않다.** 미국 Blurred Lines 판결(2018)
- **실제로 걸리는 곳은 Content ID다.** 음원뿐 아니라 멜로디도 맞춰 본다.
- **역설:** 사람의 창작 기여가 없는 AI 생성물은 저작권 보호를 받지 못한다(미국 저작권청, 한국 저작권위원회 안내).
  - 결과물은 우리 것도 되지 못한다.
  - 그래서 자산은 **결과물이 아니라 형식(포맷)** 이다. 형식은 채널 정체성, 세계관, 상표로 지킨다.
- **공공 영역 자원:**
  - Dies irae(13세기 그레고리오 성가, 선율과 가사 모두)
  - 레퀴엠 미사 전례문
  - 불가타 성경
  - SATOR 마방진

| 가져와도 되는 것 | 가져오면 안 되는 것 |
|---|---|
| 템포대, 단조, 합창과 오르간 편성, 의식 같은 분위기 | 레퍼런스 곡의 실제 음 순서(멜로디 윤곽) |
| 라틴어 종말론 어휘, INRI, Abracadabra, Dies irae 선율 | 레퍼런스 곡의 특정 화성 진행과 리듬의 결합 |
| "주문어 반복" 같은 추상적인 음절 골격 | 레퍼런스 오디오를 생성 모델의 참조 입력(cover)으로 넣는 것 |

## 2. 구조 — "우리 곡"을 자기복제한다

1. **틀(문법)**
   - 후렴 음절 골격을 우리가 정한다. 예: `2·2·5·2·2`(단어 ×2, 다섯 음절 주문어, 단어 ×2)
   - 그 위의 멜로디는 반드시 새로 만든다.
2. **모체곡**
   - ACE-Step으로 여러 개 만들어 보고 사람이 하나를 고른다. 이 선택이 사람의 창작 기여가 된다.
   - 고른 곡의 멜로디를 고정한다.
3. **가사 생성기(LLM)**에 거는 제약
   - 음절 수를 맞춘다.
   - 라틴어 강세 규칙: 끝에서 두 번째 음절이 길면 거기, 짧으면 끝에서 세 번째 음절에 강세를 둔다.
   - 긴 음표에는 a·o 같은 열린 모음을 둔다.
   - 각운을 맞춘다.
   - 어휘는 공공 영역 문헌에서만 쓴다.
   - 예: `CINIS CINIS · TETRAGRAMMATON · CINIS CINIS`
   - 예: `SATOR SATOR · MEMENTO MORI · SATOR SATOR`
4. **변이 생성(ACE-Step 1.5)**
   - **약하게 고정:** 같은 시드, 태그, BPM, 키에 가사만 바꾼다. 가사가 바뀌면 멜로디도 흔들리므로 같은 분위기의 변주 정도로만 쓸 수 있다.
   - **강하게 고정:** repaint 또는 가사 편집(cover) 기능에 **우리 모체곡**을 참조로 넣는다. 멜로디를 잠근 채 가사만 바꾼다.
5. **검수**
   - Whisper로 가사가 알아들리는지 확인한다.
   - 음높이 윤곽을 뽑아 음정 간격 n-gram을 비교한다.
     - 레퍼런스 곡과는 **멀어야** 하고, 모체곡과는 **가까워야** 한다.
   - 공개하기 전에 비공개로 올려 Content ID에 걸리는지 확인한다.

## 3. 플랫폼 리스크

- 유튜브 수익화 정책의 "진정성 없는 콘텐츠(inauthentic content)" 조항이 걸린다. 2025년 7월에 "반복적 콘텐츠"에서 이름이 바뀌었다.
  - 같은 틀에 가사만 바꾼 곡을 양산하면 거절 사유가 된다.
- **대응:**
  - 변이 여러 개를 한 영상 안에서 하나의 의식으로 엮고, 각 변이에 의미를 붙인다. 예: 1장 재(CINIS), 2장 피(SANGUIS)
  - 무엇을 남길지는 사람이 고른다.
  - 무한 생성은 재료를 만드는 단계까지만 맡긴다.

## 5. 시험 1 결과 (2026-10-14)

- **설정:** ACE-Step 1.5 XL, 120초, 84 BPM D단조, `language=la`, 가사 6벌(`config/lyrics.json`)
  - 모체곡: Dies irae 1~2연과 후렴 "Cinis… tetragrammaton…"
  - 변이곡: 같은 8음절 운율로 새로 쓴 가사 5벌
- **비용:** 25곡, RTX PRO 4500(시간당 0.72달러)
  - 기동 약 3분, turbo 곡당 약 27초, sft 곡당 약 45초. 전체 30분 미만, 약 0.35달러
  - 결과를 로컬로 받은 뒤 팟은 지웠다(상태 확인: 팟 없음).
- **측정 도구**
  - `tools/melody_sim.py`: 모체곡과 같은 시점의 크로마(12음) 유사도. **멜로디가 잠겼는지**를 본다.
  - `tools/lyrics_check.py`: Whisper(small)로 받아 적어 자기 가사의 소리와 모체 가사의 소리를 각각 몇 % 담았는지 잰다. **가사가 바뀌었는지**를 본다.

| 방식 | 모체와 닮음 | 자기 가사 / 모체 가사 | 판정 |
|---|---|---|---|
| 기준선: 같은 가사, 시드만 다름(모체 후보 s2~s4) | 0.68~0.74 | — | 멜로디가 다름 |
| 약한 고정: 같은 시드, 가사만 바꿈 (turbo) | 0.68~0.73 | 0.59~0.75 / ≤0.03 | 가사는 또렷하지만 **멜로디가 새로 나옴** |
| 약한 고정 (sft, sft 모체와 비교) | 0.65~0.67 | 0.71~0.87 / ≤0.01 | 위와 같음 |
| **모체 출발 denoise 0.5** | **0.91~0.93** | 0.28~0.63 / ≤0.05 | **멜로디는 잠기고 가사는 새것.** 발음은 조금 뭉개짐 |
| 모체 출발 denoise 0.7 | 0.74~0.80 | 0.52~0.70 / ≤0.02 | 가사는 또렷해지지만 멜로디가 풀림 |

- **결론:** "멜로디는 두고 가사만 무한히 바꾼다"는 구조는 **모체 출발(audio-to-audio) denoise 0.5 부근에서 성립한다.**
  - 시드만 고정해서는 안 된다. 가사가 바뀌면 언어 모델이 곡 설계(오디오 코드)를 새로 하기 때문이다.
- **멜로디 고정과 가사 전달은 서로 당긴다.** denoise 0.5는 멜로디 쪽, 0.7은 가사 쪽이다.
- **모체 후보 s2:** Whisper가 아무것도 받아 적지 못했다. 노래가 거의 없는 곡일 수 있다. 모체를 고를 때 들어 보고 확인한다.
- **청취 페이지:** https://claude.ai/artifact/CTBVJuj57K9gwhx9vE4E6f (비공개)
  - 듣던 위치를 유지한 채 모체곡과 변이곡을 번갈아 누를 수 있다.

### 다음 시험(exp2) 후보

1. denoise 0.55와 0.6을 시험해 멜로디 고정과 가사 전달의 균형점을 찾는다.
2. 모체 출발에서 `--no-codes` 를 켠다. 언어 모델이 다른 곡을 설계하려는 힘을 빼면 낮은 denoise에서도 가사가 또렷해지는지 본다.
3. `ReferenceTimbreAudio` 에 모체곡 잠재를 넣어 음색까지 고정해 본다.
4. 모체곡을 사람이 고른다: 후보 4개 중 노래가 또렷하고 후렴이 기억에 남는 것.
5. 측정에 레퍼런스 곡(「Воланд」)과의 거리를 넣는다. 원곡 음원을 쓰지 않으려면 사람이 들어서 판정하거나, 공개된 악보의 음정 패턴과 비교한다.
